# Tyllage `.github`

This repository holds Tyllage LLP's organisation-wide GitHub files.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public introduction shown on [github.com/Tyllage](https://github.com/Tyllage) |
| [`SECURITY.md`](SECURITY.md) | How to report a security issue privately |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Outside contributions are not accepted |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expected behaviour in Tyllage project spaces |
| [`SUPPORT.md`](SUPPORT.md) | Where to send enquiries |
| [`.github/`](.github) | Default issue and pull request templates |

GitHub applies these community health files to every Tyllage repository that does not have its own version. A repository's own file always takes priority.

**Licences are not inherited.** Every Tyllage repository must contain its own `LICENSE` file (the Tyllage Proprietary License). The [`LICENSE`](LICENSE) here covers this repository only, including the Tyllage logo and profile content.
